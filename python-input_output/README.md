# Python - Input/Output

This directory contains Python scripts for reading and writing files, working with JSON serialization/deserialization, and implementing classes with JSON conversion methods.

## Files

- `0-read_file.py` - Read a text file (UTF8) and print to stdout
- `1-write_file.py` - Write a string to a text file
- `2-append_write.py` - Append a string to a text file
- `3-to_json_string.py` - Return the JSON representation of an object
- `4-from_json_string.py` - Return an object represented by a JSON string
- `5-save_to_json_file.py` - Write an Object to a text file using JSON
- `6-load_from_json_file.py` - Create an Object from a JSON file
- `7-add_item.py` - Script that adds arguments to a Python list and saves to file
- `8-class_to_json.py` - Return dictionary description of an object for JSON
- `9-student.py` - Student class with to_json method
- `10-student.py` - Student class with attribute filtering
- `11-student.py` - Student class with reload_from_json method
- `12-pascal_triangle.py` - Generate Pascal's triangle
